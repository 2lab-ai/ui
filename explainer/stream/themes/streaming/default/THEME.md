# Streaming theme `default` — 치지직(CHZZK) 방송 화면

화면 구성:
- **채팅:** 오른쪽 위, 어두운 유리 패널. 헤더는 "채팅"과 초록 점이다.
  - **메시지만 보이고 닉네임은 없다**(오너 규칙). 색 점으로만 시청자를 구분한다.
- **제목 라벨:** 채팅 아래. 방송 제목은 콘텐츠의 `STREAM_TITLE`에서 오고, 오른쪽에 현재 시각이 붙는다.
- **후원 알림:**
  - 화면 표시: "1,000**치즈** 후원!"과 메시지. 이름은 없다. 유리 카드에 초록 테두리, 살짝 튀어 오르며 나타난다.
  - 소리: 차임 뒤에 기계음 TTS(macOS `say -v Yuna`)가 **메시지만** 읽는다. 스트리머는 이름 없이 반응한다("오, 천 치즈 감사합니다!").
- **자리비움 배너:** 왼쪽 아래 "🚽 잠깐 화장실!"과 지난 시간(mm:ss). 스트리머가 단축키로 켜고 돌아와서 끈다.
- **강조색:** `#00ffa3`(치지직 초록).

채팅 흐름 규칙(콘텐츠 대본이 지킨다):
- 평소엔 잔잔하고, 아무 반응 없는 구간도 있다.
- 사건(등장, 후원, 웃음, 복귀) 직후 1~3초 늦게 몰린다.
- 잡담은 이미 나온 내용만 언급한다. 아직 나오지 않은 주제를 미리 꺼내면 대본 티가 난다.
- 질문 몇 개는 답 없이 흘려보낸다.
- 상황을 설명하는 말투("속삭이는 거 개웃김")보다 짧은 반응("ㅋㅋㅋ", "???")이 많아야 한다.

바꿀 수 있는 것: `theme.json` `strings`(문구), `donation_tts`(목소리, 속도), `layout.chat`, `layout.label`, `overlay.css`.
다른 플랫폼 테마는 이 폴더를 복사해서 문구, CSS, 후원 단위를 바꾸면 된다.
