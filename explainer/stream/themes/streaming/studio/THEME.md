# Streaming theme `studio` — 관객 없는 녹화 (스트리밍 북)

요약: 혼자 녹화하는 영상의 화면이다. 채팅, 후원, 시청자 수, 자리비움 배너, 라이브 시계가 없다. 채팅 자리에는 오늘 책의 목차가 있고, 지금 설명하는 부분에 불이 들어온다. 맨 아래 가는 막대는 영상이 얼마나 지났는지 보여 준다.

- 쓰는 곳: 스트리밍 북(`book/README.md`). `--streaming studio`.
- `theme.json` `"solo": true` → 빌더가 채팅·후원·자리비움을 거부하고(관객이 없다), 아바타는 채팅 쪽을 흘끗 보지 않으며, 리뷰는 각 테마의 `review_solo` 줄로 채점한다(합 100). `review_goal`이 리뷰 프롬프트의 목표 문단을 바꾼다.
- 목차: beats의 `TOC = ['…', …]`(부분 제목, 7~10개), 부분이 바뀔 때 `B.chapter(i)`. 패널 제목은 `STREAM_TITLE`.
- 위치: `layout.toc`(채팅 상자 자리, 1292,28 600×452). 아바타는 스트리머 테마 그대로.
- 색: `#b18cff`(연보라, 책듣는밤의 보랏빛 소).
