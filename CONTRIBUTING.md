# Contributing

Issues and pull requests are welcome.

- How the library is built and the component contract: `AGENTS.md`.
- Before a pull request: `npm run verify` (biome, typecheck, tests, site build, consumer check) passes.
- Conventional commits (`feat(context-window): …`, `fix(dialog): …`).
- Only original work or code under a licence compatible with MIT; name the source of anything ported (see `licenses/`).

By contributing you agree that your contribution is licensed under the MIT licence of this repository.
